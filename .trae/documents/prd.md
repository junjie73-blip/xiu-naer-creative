# 修哪儿 H5 Demo 产品需求文档

## 1. 产品概述
修哪儿是一款面向社区居民的报修进度追踪 H5 应用，解决"报修后石沉大海"的痛点，让居民像查快递一样查看公共设施报修进度。
本 Demo 目标：在最小成本内验证核心闭环（拍照上报 → AI 识别 → 进度追踪 → 完成评价），并规避微信小程序上架审核周期。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册/登录方式 | 核心权限 |
|------|--------------|----------|
| 居民 | 手机号 + 短信验证码（Demo 阶段可模拟） | 提交报修、查看进度、完成评价 |
| 物业/维修人员 | 后台账号密码（Demo 阶段可模拟） | 接单、更新工单状态 |

### 2.2 功能模块
1. **首页**：社区入口、最近报修、服务介绍。
2. **报修页**：拍照上传、AI 识别分类与严重度、补充描述、提交工单。
3. **进度追踪页**：快递式时间线、当前状态、预计完成时间、完成评价。
4. **我的报修列表页**：历史工单卡片、状态筛选、快速进入详情。

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 社区入口 | 扫码/选择社区，展示当前社区名称与入口二维码 |
| 首页 | 最近报修 | 展示用户最近一次报修的简要状态与快捷入口 |
| 首页 | 服务介绍 | 用 3 张卡片说明"拍照 → AI 识别 → 追踪 → 评价"流程 |
| 报修页 | 拍照上传 | 调用相机/相册，支持预览与重新拍摄 |
| 报修页 | AI 识别结果 | 展示 AI 预测的问题类型与严重度，允许用户手动修正 |
| 报修页 | 描述与位置 | 文本输入框、自动获取定位、地图标记（可选） |
| 报修页 | 提交工单 | 提交后生成单号，跳转进度页 |
| 进度追踪页 | 快递式时间线 | 按时间倒序展示"已提交/已受理/处理中/待验收/已完成"节点 |
| 进度追踪页 | 工单信息 | 展示单号、问题类型、严重度、图片、描述 |
| 进度追踪页 | 评价模块 | 状态为"已完成"时显示星级评分与文字评价 |
| 我的报修列表页 | 工单卡片 | 每张卡片展示缩略图、类型、状态、时间 |
| 我的报修列表页 | 状态筛选 | 支持按"全部/处理中/已完成/已超时"筛选 |

## 3. 核心流程
居民打开 H5 → 选择/扫码社区 → 进入报修页 → 拍照并补充描述 → AI 识别问题类型与严重度 → 提交工单 → 系统派单 → 居民在进度页查看快递式时间线 → 维修完成后居民评价。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：政务蓝 `#2563EB` 为品牌主色，活力橙 `#E85D3A` 为强调色，背景使用浅灰 `#F8FAFC`。
- **按钮风格**：大圆角胶囊按钮（`border-radius: 9999px`），主按钮使用渐变背景（蓝到紫）。
- **字体**：中文优先使用系统字体栈（PingFang SC、Microsoft YaHei），标题加粗，正文 16px。
- **布局**：移动端优先的卡片式布局，顶部固定导航，底部安全区留白。
- **图标/emoji**：使用 emoji 降低认知成本，如 📷 拍照、🔧 维修、⭐ 评价。

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | Hero 区 | 渐变大标题、社区选择器、扫码入口按钮 |
| 首页 | 流程说明 | 4 个横向步骤卡片，带图标与微动画 |
| 报修页 | 表单区 | 图片预览网格、AI 结果标签、文本域、定位按钮 |
| 进度追踪页 | 时间线 | 左侧竖线节点、右侧状态卡片、当前节点高亮脉冲 |
| 我的报修列表页 | 列表区 | 下拉刷新、卡片骨架屏、状态色标 |

### 4.3 响应式
- 设计基准为移动端（375px 宽度），向上适配至平板与桌面。
- 核心交互以触摸为主，按钮最小点击区域 44×44px。
- 图片上传组件在桌面端支持拖拽上传。
